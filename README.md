# Parcl Buyer Segmentation

An end-to-end Machine Learning pipeline and interactive Streamlit web application designed to segment potential property buyers based on behavioral, transaction, and demographic data.

---

## 📌 Project Overview
Customer segmentation enables targeted marketing, better engagement, and data-driven product strategies. This project processes raw buyer data, applies clustering/classification models, and presents the insights via an interactive dashboard.
